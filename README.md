# 💻 Manas Suple — Portfolio Website

Hey there 👋  
I’m **Manas Suple**, a student and aspiring backend developer with a growing passion for design, AI, and building real-world projects.
This is my personal **portfolio website**, built to showcase my projects, skills, certifications, and experiences.  
It reflects my journey as a developer and designer, my learning mindset, and my passion for creating clean, functional digital experiences.

---

## 🧠 About the Website

I designed this site to highlight my growth — both technically and creatively.  
It’s built using **Next.js** with a focus on **smooth animations, responsive layouts, and minimal UI**.

Every section — from the hero text to project cards — represents a part of my journey in tech.

---

## 🚀 Tech Stack
- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **UI Components:** shadcn/ui
